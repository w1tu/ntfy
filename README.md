# <img src="assets/ntfy-icon-256.png" width="32" height="32" align="absmiddle"> ntfy

ntfy is an iOS tweak that replaces red notification badges. Inspired by Dotto+.

- Filled or hollow dots, with adjustable size, ring thickness, opacity and position
- Preset colours, any custom colour, or adaptive colours picked from each app's icon
- Optional pastel look
- Works on app icons, folders and the dock
- Changes apply instantly, no respring needed

Supports iOS 15–26 on rootless and rootful jailbreaks.
